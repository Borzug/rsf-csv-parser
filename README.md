# Rally Race Chart

https://borzug.github.io/rsf-csv-parser/

Приложение для визуализации и анализа результатов ралли из CSV-файла (экспорт rallysimfans.hu).
Приложение полностью сгенерено через Claude (даже это readme).

Интерфейс доступен на русском, английском и венгерском (переключатель в шапке, выбор запоминается).

## Сборка и запуск

```bash
npm install
npm run build
```

Сборка кладёт бандл в `dist/renderer/index.js`. Страница использует ES-модуль, поэтому `index.html` нужно открывать через любой статический сервер, а не как файл, например:

```bash
npx serve .
```

Для разработки — `npm run dev` (пересборка при изменениях), проверка типов — `npm run typecheck`.

## Экран загрузки

- **Название события** — необязательное поле, показывается в заголовке.
- **Выбрать CSV-файл** — диалог выбора файла. Файл можно и просто **перетащить в окно** — в том числе поверх уже открытого графика, чтобы сменить ралли.
- Ожидается таблица результатов онлайн-ралли с rallysimfans.hu (файл вида `105003_table.csv`).
- Кнопка **← Назад** на экране анализа возвращает сюда, не теряя данных: кнопка **«Вернуться к анализу»** открывает график с прежними фильтрами.

## Заголовок

- Название: введённое вручную → название ралли с rallysimfans → номер ралли из имени файла («Ралли #105003»). Рядом — ссылка **rallysimfans ↗** на страницу ралли.
- Статистика: «финишировали 125 из 200 · СУ: 2».

**Какие данные уходят наружу:** чтобы показать название ралли, приложение отправляет через сервис Google только номер ралли из имени файла. Содержимое CSV никуда не отправляется. Google при этом виден IP-адрес пользователя.

## Вкладка «График»

### Как читать график

- **Ось X** — каждый спецучасток (SS) разделён на три точки: SP1, SP2 и финиш. Под осью — названия спецучастков.
- **Сплошная линия** — успешное прохождение, **пунктир** — Super Rally, **◆** — точка с комментарием. Обозначения продублированы над графиком.

### Режимы оси Y

Переключатель над графиком:

- **От лидера** (по умолчанию) — отставание от самого быстрого на каждом сплите. Лидер идёт по нулю вверху, остальные ниже. Самый наглядный режим для борьбы за места.
- **Время** — накопленное время. Все стартуют из нуля, победитель заканчивает ниже всех.
- **Позиция** — место в общем зачёте на каждом сплите среди показанных участников: видно, кто кого и где обогнал. Удобнее всего с выборкой («Топ-20», один класс); сошедший выпадает, остальные поднимаются. В подсказке — место и отставание от лидера.
- **От выбранного** — отставание от первого закреплённого участника (доступно, когда кто-то выбран). Остальные линии лишь слегка приглушены — видно, кто быстрее и медленнее выбранного и на каких участках.

В режимах отставания при сравнении двух и более участников шкала подстраивается под них.

### Выделение и сравнение

- **Наведение** на линию выделяет её и показывает подсказку: этап, участник, автомобиль, время, отставание (в режимах отставания), штрафы, Super Rally, комментарий.
- **Клик по линии** или по имени в легенде закрепляет участника: над графиком появляется плашка с именем, над его ◆ — номера СУ, а под графиком — лента его комментариев (см. ниже).
- **Ctrl/Shift + клик** добавляет участника к сравнению (на сенсорных экранах — просто касание имени в легенде). Подсказка над точкой закреплённого показывает таблицу всех сравниваемых на этом сплите с отставанием от быстрейшего.
- **×** на плашке убирает одного участника, **Escape** или клик по пустому месту — всех.
- **Клик по названию спецучастка** под осью оставляет только этот SS; повторный клик возвращает прежний выбор.

### Комментарии на графике

- **Лента под графиком** — комментарии закреплённых участников по порядку СУ (при сравнении — с именами). Наведение на запись обводит точку на графике, наведение на ◆ подсвечивает запись. Клик по записи оставляет на графике только этот СУ, повторный клик возвращает прежний выбор. Ленту можно свернуть, это запоминается.
- **💬 N под осью** — сколько комментариев на каждом СУ: у закреплённых, а если никто не закреплён — у всех показанных. Наведение (на телефоне — касание) открывает список этих комментариев по месту на СУ; клик закрепляет список открытым, клик мимо или **Esc** закрывает.

### Легенда (правая панель)

Список видимых участников в порядке линий на графике сверху вниз. Наведение подсвечивает линию, клик — закрепляет. Если список не помещается, кнопка **‹** расширяет панель. Цвета назначены по итоговому месту, поэтому у соседей по таблице (и по графику) они заметно различаются.

**Поиск** над списком (клавиша **/** переводит в него курсор) не скрывает участников, а переходит к ним: совпадения отмечаются жёлтым, легенда прокручивается к текущему, его линия выделяется на графике. **Enter** добавляет его к сравнению (повторно — убирает), **↑/↓** — следующее/предыдущее совпадение, **Esc** — очистить поиск.

## Боковая панель фильтров

Группы сворачиваются кликом по заголовку; в заголовке — счётчик выбранных/всего. Кнопки **Все** и **Ничего** подсвечиваются, когда выбраны все или ни одного.

### Фильтры на вкладке «График»

- **Спецучастки** — какие SS показывать; отсчёт времени начинается с первого выбранного.
- **Участники** — отсортированы по итоговому месту (сошедшие — в конце с пометкой DNF). Поиск от 2 символов. Быстрый выбор: **Топ-10**, **Топ-20**, **Финиш** — учитывают фильтр класса, т.е. «Топ-10» при выбранном классе — десятка этого класса.
- **Группа / Класс** и **Автомобиль** — скрывают участников остальных классов/машин.

### Фильтры на вкладке «Результаты»

- **Этапы** — по каким спецучасткам считать итоговое время.
- **Участники** — выбор конкретных участников.
- **Класс** — лидер и отставания считаются внутри выбранных классов.

## Вкладка «Результаты»

Таблица итоговых мест по возрастанию суммарного времени. Колонки **#** и **Участник** остаются на месте при горизонтальной прокрутке.

| Столбец | Описание |
|---|---|
| **#** | Итоговое место; у сошедших — DNF |
| **Участник** | Логин и реальное имя |
| **Класс**, **Автомобиль** | Класс и модель |
| **Общее время** | Сумма по выбранным этапам |
| **Штрафы** | Штрафы и сервисные штрафы |
| **Темп/км: лидер** | Отставание от лидера в секундах на километр (с учётом SR) |
| **Темп/км: пред.** | Отставание от предыдущего места в секундах на километр. Красный — отставание, зелёный — опережение |
| **Чист. темп/км: лидер / пред.** | То же, только по участкам без SR у обоих; в подсказке — по скольким этапам посчитано |
| **Общее отставание** | Разница с лидером |
| **SR** | Количество Super Rally |
| **SS1, SS2, …** | Время на спецучастке и место на нём (среди участников в таблице); **SR** — участок пройден по Super Rally |

У сошедших колонки темпа пустые — по неполному набору участков они вводили бы в заблуждение.

**Длина СУ** берётся по названию из справочника трасс rallysimfans (`src/renderer/data/stages.json`); в подсказке к заголовку SS видна длина. Темп на км = сумма отставаний / сумма километров. Если для какого-то из выбранных СУ длина неизвестна (например, у ралли со своими названиями вроде «Cumbre 1»), колонки переключаются на прежний режим **Темп/СУ** — среднее отставание за участок.

- **Поиск участника** — клик по заголовку «Участник» превращает его в поле ввода; таблица прокручивается к найденной строке.
- **Выбор строк** — клик (или Enter/пробел с клавиатуры) отмечает строку. Кнопка **«Применить фильтр по участникам»** оставляет в таблице только отмеченных.

## Ссылка на текущий вид

Адрес страницы хранит вкладку, режим оси Y, выбранные спецучастки и классы и закреплённых участников, например:

```
…/rsf-csv-parser/#r=105003&y=pinned&ss=2&pin=CRG+AleX%7Cdrayleigh
```

Сами данные в ссылку не попадают — это локальный файл. Открыв ссылку и загрузив тот же CSV, вы (или тот, кому вы её отправили) увидите тот же вид. Номер ралли (`r`) сверяется с именем файла, поэтому настройки от другого ралли не применяются.

## Клавиатура, телефон

- Все элементы управления доступны с клавиатуры (Tab, Enter/пробел, Escape).
